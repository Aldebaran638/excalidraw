# Excalidraw 产品工程

以 Notion 产品工程师级别的产品与工程标准工作；这是质量视角，不是真实任职身份。

## 设计决策

- 先明确用户任务、主操作和信息层级，再安排控件。逐级展示高级能力，避免常驻按钮堆叠和无意义模式切换。
- 交互友好与视觉美观同等重要。检查字体层级、行长、留白、对齐、语义配色、图标、边框和元素样式；既不能只有功能，也不能以装饰牺牲可读性。
- 复用项目的按钮、Sidebar、Dialog、图标与主题变量。不同内容可有不同布局，不把所有模块强行套进同一张卡片。
- 覆盖空状态、加载、错误、取消、停止、恢复和保存反馈。只显示真实阶段；失败保留用户输入，不把未保存显示为成功。
- 检查中文长文本、长列表、极小区域、明暗主题、键盘、输入法、触屏和窄屏。文字不能靠整体缩小硬塞进区域，重要操作不能被遮挡。

## 用户明确的界面偏好：稳定、连贯、不跳变

以下是本项目用户已经明确表达的体验要求，设计与评审时主动遵循，而非等用户再次指出：

- 同一个面板的不同标签必须共用同一个外壳容器、尺寸来源和定位规则。切换的是内容，不是整套容器；不能因切到聊天、素材库、搜索或空状态而改变面板宽高、停靠方式或画布预留空间。
- 标签栏、关闭按钮等公共导航应保持相对屏幕的位置稳定。内容长短、加载状态、滚动条出现或异步结果到达，不应推动它们跳动。不要用过渡动画掩盖结构性尺寸跳变。
- 侧栏宽度由用户控制：桌面支持边界拖动，所有标签共享并记住宽度；允许用户明确恢复默认。仅在用户调宽或视口变化需要适配时改变外壳尺寸，不按当前标签自动调宽。移动端可采用适合窄屏的统一外壳，不照搬桌面拖宽。
- 侧栏是可以与画布并行工作的区域，不是点外部就消失的临时菜单。点击笔记区应允许继续编辑而不关闭侧栏；关闭使用明确入口或约定快捷键。不要通过强制停靠来绕过此要求。
- 内容适应容器，而不是容器随内容忽大忽小：使用响应式排版、换行和必要的局部滚动，不缩小整块内容硬塞，也不让操作区被挤出可视范围。切换标签不应无故清空输入、重置组件或丢失各标签的阅读位置。
- 文本输入默认采用软换行：长行在容器内自动折行显示，不出现横向滚动条，也不向实际文本插入换行符。检查连续英文、URL、中文及窄屏；只有明确需要保留横向布局的专用编辑器例外。聊天正文应可直接拖选和复制，不能继承画布的禁止选择行为。
- 滚动区域优先使用覆盖在内容上方、不占布局空间的浮动滚动条，保留鼠标拖动、滚轮、键盘与触屏滚动。不要让滚动条出现／消失挤窄内容、改变换行或导致相邻组件尺寸跳变；不能只隐藏原生滚动条而取消可拖动的替代入口。组件内的纵向、横向及嵌套滚动均需检查。
- 常用操作优先使用纯图标，而非成排文字按钮：例如思考用大脑、复制用重叠矩形、重新生成用循环箭头、编辑用铅笔、发送用向上箭头、停止用实心方块。复用项目统一风格的 SVG 图标，不用 emoji 代替操作图标；低频操作收进更多菜单，避免图标堆叠。
- 图标按钮须有悬停／键盘聚焦提示和无障碍名称；开关通过背景、边框等辅助颜色区分状态。消息操作默认轻量无边框，悬停与聚焦时加强；触屏不依赖悬停，点击区域至少 44px。为操作区保留尺寸，复制成功切换为对勾、发送原位切换为停止时，不推动正文或改变导航位置。
- 画布内 HTML 应用默认没有常驻装饰外框，选中框与调整手柄使用原生机制。宿主标题与操作仅在原生选中时显示，编辑、重新运行、放大集中为右上角图标；显隐不改变应用视口或重启运行实例。宿主和页面外围默认透明，保留内部卡片与控件底色，不能通过全局清除背景破坏内容层次；静态导出与画布透明效果一致。
- 纯图标偏好针对操作入口，不要求隐藏信息：错误、保存结果、风险及破坏性操作确认继续用清楚的文字说明。输入区保持辅助图标与主发送按钮的位置稳定，避免常驻状态文案挤占空间。

## 提示与按钮：轻量、统一、不溢出

- 普通画布操作指引默认采用用户选定的方案 A：纯文字，无外框、底色、阴影或模糊效果，不套成表单、卡片或警告框。需要持续引导的模式只保留一处常驻指引，不再叠加内容相同的 Toast；用户取消或完成放置后整条指引直接消失，不出现“已取消”“已放置”“再试一次”或额外成功 Toast。其他短暂操作结果仍可使用原生 Toast；冲突、失败和需用户决策的信息按严重程度明确呈现，不为了统一风格弱化重要反馈。
- 同类提示共用定位、间距、字号、语义颜色与取消方式。画布指引锚定当前可用画布区域，避让侧栏、工具栏及触屏安全区；不改变视角、缩放或面板尺寸。说明写清当前动作，桌面可附 Esc 键盘提示，并使用唯一、可点击的“取消”文字按钮；这是纯图标操作偏好的明确例外，不再同时摆放叉号。按钮须有无障碍名称及清楚的聚焦状态，触屏操作区至少 44px。
- **按钮内的文字、图标及状态标记永远不得超出按钮边界，也不得重叠。** 文本按钮按内容计算宽高并预留内边距，不能直接把多字标签塞进默认方形图标按钮；在弹性布局中为操作保留最小尺寸，不让长说明把按钮挤瘪。
- 空间不足时先让说明自然换行、调整操作排列或使用含义清晰的图标入口；长按钮标签确需换行时按语义折行并让高度增长，禁止逐字竖排、裁掉关键操作文字、用隐藏溢出或缩小字号掩盖尺寸错误。此规则适用于应用宿主，也纳入 AI 生成界面的预览检查；不能承诺静态校验能保证任意生成代码正确。
- Tooltip 是独立浮层，不要求塞在按钮内部，但其文字同样不得溢出自身容器，并须避让屏幕边缘。验收区分按钮标签和 Tooltip，检查中文、英文长词、窄屏、侧栏调宽、明暗主题、触屏及浏览器放大，确认实际内容和点击区域完整。

## 架构与数据

- 沿用原生元素、历史和扩展接口；应用业务放在应用层，共享定义及运行时集中维护，核心画布只增加通用能力。不为新功能建立平行场景系统。
- 笔记 Agent 使用 Pi SDK 编排模型、工具循环和会话上下文；笔记工具、源码候选、预览验收与确认应用由场景层负责。新增场景通过配置提示、工具及资源接入，不重新建立模型循环或叠加通用重试。Pi 会话保存在当前笔记目录 `.chats/<noteId>/pi/<sessionId>/`，与界面记录通过稳定身份及持久提交关联；不能用修改内存消息数组代替历史恢复。
- Agent 专属服务端代码统一放在 `excalidraw-app/server/agent/`，应用组装从该目录 `index.ts` 接入；新增编排、模型通信、工具、恢复及通信日志模块不要散落到服务端根目录。笔记身份、会话持久化和 HTML 源码／版本等被多业务使用的能力保留在共享层，不能为了目录归类让它们反向依赖 Agent。目录组织不要求拆成独立进程或服务。
- 保持笔记身份、会话身份、元素身份与内部节点作用域清晰。异步响应必须绑定原目标，不能覆盖切换后的笔记。
- 不以渲染、悬停、滚动或动画触发笔记写盘。保留串行保存、revision/ETag、自身事件抑制及外部更新冲突保护。
- 打开面板、自动保存、流式更新不能重置画布视角、缩放或历史。未确认的 AI 候选不写入场景。
- 新增 DOM/browser API 使用 app.ownerDocument、app.ownerWindow；无 app 时从挂载节点取得 ownerDocument/defaultView。
- AI 数据是非可信输入：校验定义、工具参数和目标范围。允许聊天中的 HTML/CSS/JavaScript 在隔离预览中运行，不直接在宿主页面执行；默认禁止访问宿主数据、网络、弹窗及顶层导航。旧声明式组件继续沿用原校验与运行时。
- 允许 AI 应用使用 React、D3、Mermaid 等经过验收的常用库，优先使用共享注册表内的本地打包加载，固定版本 CDN 作为可选入口；这不授予任意联网或宿主执行能力。版本、模型能力说明、校验与运行时白名单共用来源，新增依赖须测试实际加载、交互、离线本地路径与失败反馈，不能只在提示词中宣称可用。
- 笔记 Agent 的验收以真实任务完成为准：普通聊天、简单与复杂应用创建、原生导入、连续局部修改及确认应用。可恢复的协议失误、缺失产物和截断由程序在同一任务中有界恢复，不将模型的成功文字当作成功；停止、存储失败和冲突保护不可绕过。正常与失败重试预算独立，保留绝对时限；明确报告真实模型回归的样本量和失败，不把模拟通过当作生产成功率。
- 新 AI 应用统一使用 HTML/CSS/JavaScript，通过聊天创建和修改，不新增旧 JSON 组件或恢复独立 JSON 创作入口。聊天和原生 embeddable 共用 iframe 运行时；源码权威存于笔记目录 `.apps/<noteId>/<appId>/versions/<version>/source.html`，笔记内的校验快照用于携带与明确恢复，不作为第二个编辑来源。
- 修改明确引用的应用时，先读当前源码与哈希，再做唯一文本匹配或已完整读取行范围内的原子局部替换；先展示候选与差异，由用户确认才更新画布。保留元素 ID、位置、尺寸和最新持久状态；源码更新会重新运行，不能承诺保留任意闭包或焦点。复制、另存为和重复导入应独立身份与状态，不能按名称猜测实例。
- 导出 HTML 应用必须捕获当前运行画面，失败要明确提示，不能用旧截图或空白占位冒充成功。模型源码只在隔离 iframe 执行；宿主只接受受限静态图像，不导出可执行 HTML。
- 保留用户未提交的笔记和计划改动。3009 本身就是共用测试程序，固定使用项目根目录 `.local-data/preview/notes/`，包括其中的 `.chats/` 会话及组件；更新只换程序，不换数据目录，不再切到临时隔离环境。验收使用唯一命名的新增样例，清理仅针对本次样例，不能重置用户数据；3001 不动。单元测试仍可使用临时文件，不得据此切换应用挂载。

## 验收

用真实任务走完整流程，并检查浏览器截图和实际操作。类型检查、单元测试、接口成功不能替代交互与视觉验收。按风险覆盖持久化、刷新、撤销、并发、异常与普通绘图回归；明确区分模拟模型测试和真实模型测试。未验证或尚未完成的部分如实报告。

涉及多标签面板时，在相同视口与用户宽度下逐项切换，比较外壳、标签栏、关闭入口和画布预留区域的实际位置及尺寸；覆盖空内容、长内容、加载与失败状态，并检查输入保留、拖宽恢复及点击画布不关闭。不能只检查单个标签的静态截图。
